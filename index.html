Projects

Tournament Slot Reservation System

A console-based application developed in C that allows users to book and monitor up to 10 game match slots. The system provides an interactive menu for booking slots, checking the status of all slots, and viewing the final slot status before exiting. It validates slot numbers, prevents double-booking, and informs users when they attempt to reserve an already-booked slot. This project demonstrates fundamental C programming skills, including arrays, loops, conditional statements, switch-case structures, and user input handling.

Repository: Tournament Slot Reservation System

Budget Management System

A console-based application developed in C that helps users track and manage their personal finances by recording income and expenses. The system allows users to add transactions, view transaction records by date or month, generate a financial summary, and save or load transaction data using file handling. It automatically calculates total income, total expenses, and the remaining balance, making it easier to monitor financial activity. This project demonstrates the practical use of C programming concepts, including functions, pointers, arrays, string manipulation, and file handling.

Repository: Accounting System

Soil Irrigation System

The objective of this project is to design and implement an automated irrigation system that detects soil moisture levels and activates a water pump when the soil becomes dry. This system aims to reduce manual monitoring of plants and ensure they receive the correct amount of water, preventing both over watering and under watering.
