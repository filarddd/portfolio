Projects

Game Match Scheduling

The system, although can only be interacted within the Terminal, will allow the user to reserve a slot for matches in a tournament, and a maximum of 10 match slots will be available. Users can book a slot, view the status of all slots, and exit the program with a summary of reservations. The system ensures no slot is double-booked.

Accounting System

The system, although the output can only be seen and interacted in the Terminal, allows users to Add Transaction, View Summary, View Transactions by Date, Save and Load Data. This project shows that basic C programming tools — functions, pointers, arrays, and file handling — are useful to build real-world applications

Soil Irrigation System

The objective of this project is to design and implement an automated irrigation system that detects soil moisture levels and activates a water pump when the soil becomes dry. This system aims to reduce manual monitoring of plants and ensure they receive the correct amount of water, preventing both over watering and under watering.
