Game Match Scheduling

This was my final project for Programming Logic and Design 1 during the first semester of my 1st year as a Computer Engineering student. This system can only be interacted within the Terminal. The system will allow the user to reserve a slot for matches in a tournament, and a maximum of 10 match slots will be available. Users can book a slot, view the status of all slots, and exit the program with a summary of reservations. The system ensures no slot is double-booked.
