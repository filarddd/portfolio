Tournament Slot Reservation System

A solo project console-based application developed in C that allows users to book and monitor up to 10 game match slots. The system provides an interactive menu for booking slots, checking the status of all slots, and viewing the final slot status before exiting. It validates slot numbers, prevents double-booking, and informs users when they attempt to reserve an already-booked slot. This project demonstrates fundamental C programming skills, including arrays, loops, conditional statements, switch-case structures, and user input handling.

Soil Irrigation System

A hardware-based automated irrigation system developed as a two-person project using electronic sensors, comparator circuits, and AND logic gates. The system monitors soil moisture and surrounding temperature, converting sensor readings into digital signals through an LM358 comparator. Using a CD4081 AND gate IC and a manual switch, the system activates a relay-controlled water pump when the required conditions are met. This project aims to reduce manual plant watering, promote efficient water usage, and help prevent overwatering and underwatering. It demonstrates the practical application of digital logic, sensor integration, analog-to-digital signal processing, and electronic circuit design without using a microcontroller.

Technologies and Components Used

CD4081 AND Gate IC · LM358 Comparator · Soil Moisture Sensor · LM35 Temperature Sensor · Relay Module · DC Water Pump · Electronic Circuit Design · Hardware-Based Automation
